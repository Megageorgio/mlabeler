mLabeler Privacy Policy

Effective date: 23 October 2026. App: mLabeler. Android package: pw.msan.mlabeler.

This policy describes how the Android version of mLabeler handles information. Developer: Megageorgio. Contact the developer at m@msan.pw. Project information is available at github.com/Megageorgio/mlabeler.

Recordings, labels and local settings

Google Play edition: this offline edition processes recordings and labels on your device. It does not include toolkit connections, developer-operated analytics or crash-report uploads, or its own APK updater. It does not request Android's network permission. Project folders are selected with Android's system document picker; the app retains access to the folders you grant. External support and policy links open in your browser.

mLabeler opens and edits audio and companion files in folders you choose. These can include voice recordings, music, phoneme and word labels, lyrics, notes, pitch data, reclists and voicebank configuration files. Local editing and the built-in quick labelling model process this material on your device.

The app stores preferences, recent folder paths, completion marks, working-time information, temporary files and crash reports locally. There is no mandatory account, advertising SDK or automatic developer-operated analytics or crash-report upload. Crash reports can contain technical details or file paths; sending one to support is your choice.

Microphone and file access

Microphone permission is used to record samples when you start recording. Recordings are saved to the selected project folder. The GitHub-distributed Android build requests broad file access so it can read recordings and write their companion annotation and voicebank files in shared folders, including batches and subfolders. The Google Play edition uses access to selected document trees instead and does not request broad file access. These permissions do not by themselves send files to the developer.

Optional mVocalToolkit connections

This section applies to builds with toolkit support, such as the GitHub-distributed Android build. These connections are not available in the Google Play edition.

If you configure a connection to mVocalToolkit and start a feature that uses it, the selected audio and relevant file names, text, labels, notes, pitch data or processing settings are sent to the server address you selected. This can be your own computer. mLabeler does not operate a mandatory processing service for these features.

The operator of that server controls access, storage, retention, any additional services it uses and deletion. Files can remain on the server after an operation finishes. Use the toolkit's storage controls or contact that server's operator to remove them. Do not assume processing is temporary or that files are deleted immediately.

Toolkit connections can use HTTP or HTTPS. HTTP does not encrypt audio, text or authentication tokens in transit. Use a trusted local network or a properly configured HTTPS endpoint. The app does not promise that every supported connection is encrypted.

Updates and external services

The GitHub-distributed Android build can check GitHub for releases and download an update after the configured update action. These requests disclose ordinary connection information, such as an IP address, to GitHub and its download infrastructure. GitHub handles that information under its own policies. Your project recordings and labels are not attached to update checks.

The app can open external websites or support links at your request. Information you choose to send using a browser, email app, a third-party server or separately installed plugins is handled by those services and the choices you make. Only install plugins and connect to servers you trust.

Retention, deletion and your choices

You control recordings and annotation files in shared project folders. Delete those files with your file manager when you no longer need them. Uninstalling the app does not necessarily remove projects stored outside the app's private storage.

You can revoke microphone or file permissions in Android settings. Clearing app storage or uninstalling removes app-private settings and caches according to Android's behaviour. Device backup or cloud-sync services can independently copy files based on your device settings; manage those copies with the corresponding provider.

There is no mLabeler account to delete. If you contact support, the information you send is used to respond to your request. To ask about or request deletion of support correspondence, email m@msan.pw. Data stored on a toolkit server must be managed with that server's operator.

Changes to this policy

The policy may be updated when the app or its data practices change. The effective date above identifies the current version.
