# mLabeler

Редактор разметки певческого голоса: слои фонем и слов, ноты и высота тона, UTAU oto. Windows, macOS, Linux,
Android и iOS из одного кода (Kotlin, Compose Multiplatform).

**Состояние:** ранняя версия. Редактор фонем работает; дальше oto, ноты и высота, плагины и авторазметка.
План — в [docs/DESIGN.md](docs/DESIGN.md).

## Что уже есть

- Открытие папки: аудиофайлы со своей разметкой (`.lab`, `.TextGrid`, метки Audacity `.txt`) — рядом с аудио или
  в папке `lab/` рядом с `wav/`.
- Волна и спектрограмма, масштаб и прокрутка (колесо, Ctrl+колесо, щипок на сенсорном экране).
- Слои интервалов: границы двигаются мышью, пальцем или клавишами; разрезать, объединить, переименовать;
  добавить, переименовать и переставить слои.
- Сдвиг следом и связанные границы — видимые переключатели; Shift/Alt меняют их во время перетаскивания.
- Отмена и повтор для каждого файла, сохранение прямо в файл разметки с копией оригинала в `.mlabeler/backup`.
- Отметки «готово», звёздочка, метка; фильтры файлов; проверки коротких и пустых интервалов и неизвестных фонем.
- Воспроизведение интервала, выделения, экрана; повтор.
- Список команд (Ctrl+K), сочетания клавиш для всего.
- Интерфейс подстраивается под окно: боковые панели на широком экране, выезжающие панели на телефоне. Панели
  можно растягивать и скрывать.
- Темы: тёмная, светлая, ретро (квадратная), контрастная. Размер интерфейса. Английский и русский.

## Сборка

JDK 17+.

```
./gradlew :app:run                     # десктоп
./gradlew :app:packageMsi              # или packageDmg, packageDeb
./gradlew :app:assembleDebug           # APK для Android (нужен Android SDK)
./gradlew :core:jvmTest                # тесты
```

iOS: `cd iosApp && xcodegen`, открыть `mLabeler.xcodeproj` в Xcode и запустить. Приложение работает в своей папке
«Документы», она видна в приложении «Файлы».

На Android приложение просит доступ ко всем файлам: разметка сохраняется рядом с записями в открытых папках.
