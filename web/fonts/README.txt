DroidSansFallback.ttf is distributed unchanged from the Android Open Source Project:
https://android.googlesource.com/platform/frameworks/base/+/android10-release/data/fonts/DroidSansFallback.ttf

It provides Chinese, Japanese and Korean glyphs to the browser renderer, which cannot
use the operating system's fallback fonts. The upstream Apache 2.0 notice and license
are reproduced in NOTICE alongside this file.

The following unmodified Noto fonts supply phonetic characters, shortcut symbols,
arrows and other interface glyphs. They are bundled locally, not loaded from Google
Fonts at runtime. Each font's SIL Open Font License 1.1 is included alongside it.

NotoSans-Regular.ttf (NotoSans-OFL.txt):
https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSans/NotoSans-Regular.ttf
NotoSansSymbols2-Regular.ttf (NotoSansSymbols2-OFL.txt):
https://github.com/google/fonts/blob/main/ofl/notosanssymbols2/NotoSansSymbols2-Regular.ttf
NotoSansMath-Regular.ttf (NotoSansMath-OFL.txt):
https://github.com/google/fonts/blob/main/ofl/notosansmath/NotoSansMath-Regular.ttf
